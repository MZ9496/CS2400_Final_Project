# Demo checklist

Use this checklist when recording the project demonstration or preparing screenshots.

- [ ] Show the repository name and selected project.
- [ ] Start from the documented command.
- [ ] Demonstrate one complete normal workflow.
- [ ] Demonstrate one empty, boundary, duplicate, or invalid-input case.
- [ ] Point out the central data structure and algorithm in the code or design document.
- [ ] Show automated tests passing.
- [ ] Show one meaningful result, report, route, compressed file, similarity score, or other project-specific output.
- [ ] Do not reveal API keys, private email, real banking data, private addresses, or personal student records.
- [ ] Keep the video focused; a 3–7 minute demonstration is usually enough.
