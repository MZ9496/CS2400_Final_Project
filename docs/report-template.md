# Project report template

Copy this file into your project repository as `docs/PROJECT_REPORT.md` and replace the prompts.

## 1. Project identity

- Project title:
- Team members:
- Repository URL:
- Selected difficulty:
- Date:

## 2. Problem and users

What problem does the application solve? Who uses it? What is explicitly out of scope?

## 3. Requirements

List functional requirements, input constraints, output requirements, and at least three assumptions.

## 4. Design

Include a small architecture or data-model diagram. Explain the role of every central data structure and the invariant it maintains.

## 5. Core algorithm

Provide pseudocode or a step-by-step explanation. Explain why this algorithm is appropriate and identify one alternative you considered.

## 6. Complexity

Define the input-size variables. Give time and auxiliary-space complexity for every required operation. If you benchmarked, include the fixture sizes, environment, measurement method, and results.

## 7. Testing

Summarize normal, boundary, invalid-input, and integration tests. Include the command used to run them and the final result.

## 8. Demonstration

Link to the demo video or list the screenshot filenames. Explain the workflow shown.

## 9. Limitations and future work

Describe known limitations, data-quality concerns, security or privacy concerns, and two realistic extensions.

## 10. Contributions and tool disclosure

Describe each team member’s contribution. Disclose any generative-AI assistance, external code, datasets, libraries, or tutorials used, including links and what was independently verified.
